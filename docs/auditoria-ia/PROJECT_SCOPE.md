# Alcance del proyecto

Este nuevo trabajo corresponde al laboratorio académico **Proyecto Integrador: Auditoría de IA y Optimización Final**. Se ejecutará exclusivamente sobre esta copia independiente de TaskMaster AI para preservar el laboratorio anterior.

TaskMaster AI será el caso práctico del escenario **EcoMart**. La auditoría posterior cubrirá:

- seguridad de la aplicación y de sus integraciones;
- políticas y configuración de Row Level Security (RLS) en Supabase;
- manejo, exposición y separación de variables de entorno;
- rendimiento del bundle y oportunidades de optimización.

Este documento define el alcance inicial. En esta etapa no se ejecutan migraciones SQL, no se modifica Supabase remoto, no se instalan dependencias y no se realizan todavía tareas de auditoría u optimización.
